1. Explain the Bias-Variance Tradeoff.

Answer:

High Bias: Model is too simple → Underfitting.
High Variance: Model is too complex → Overfitting.
Goal is to find the right balance for good generalization.

2. Why does overfitting happen?

Answer:

Small dataset
Too many features
Complex model
No regularization
Excessive training

3. How can you reduce overfitting?

Answer:

Cross-validation
Regularization (L1/L2)
Feature selection
Early stopping
Dropout (Deep Learning)
More training data
4. Explain L1 and L2 Regularization.

Answer:

L1 (Lasso)	L2 (Ridge)
Produces sparse models	Keeps all features
Performs feature selection	Shrinks coefficients
Uses absolute values	Uses squared values
5. Difference between Ridge and Lasso Regression?

Answer:

Ridge reduces coefficients but rarely to zero.
Lasso can reduce some coefficients exactly to zero, effectively selecting features.
6. What is Elastic Net?

Answer:
Elastic Net combines both L1 and L2 regularization.

7. Why is Logistic Regression called regression?

Answer:
It estimates probabilities using the logistic (sigmoid) function even though it performs classification.

9. Why can't Linear Regression be used for classification?

Answer:
It predicts unbounded continuous values instead of probabilities, making it unsuitable for classification.

10. What is the Cost Function in Logistic Regression?

Answer:
Binary Cross Entropy (Log Loss).

11. Explain Gradient Descent.

Answer:
An optimization algorithm that updates model parameters by moving in the direction that minimizes the loss function.

12. Types of Gradient Descent?

Answer:

Batch Gradient Descent
Stochastic Gradient Descent (SGD)
Mini-batch Gradient Descent
13. Why is Mini-Batch Gradient Descent commonly used?

Answer:
It balances computational efficiency and stable convergence.

14. What is the Learning Rate?

Answer:
The step size used to update model parameters during training.

15. What happens if the learning rate is too high?

Answer:
Training may overshoot the optimum and fail to converge.

16. What is Feature Scaling?

Answer:
Transforming features to similar ranges so optimization algorithms perform better.

17. Difference between Normalization and Standardization?

Answer:

Normalization: Scales values to a fixed range (typically 0–1).
Standardization: Centers data to mean 0 and standard deviation 1.
18. Which algorithms require feature scaling?

Answer:

KNN
SVM
Logistic Regression
Neural Networks
K-Means
PCA

Tree-based models generally do not require feature scaling.

19. Explain PCA.

Answer:
Principal Component Analysis reduces dimensionality by projecting data onto directions of maximum variance.

20. Why use PCA?

Answer:

Reduce dimensions
Remove redundancy
Speed up training
Improve visualization
21. What is Explained Variance?

Answer:
The proportion of the dataset's variance captured by each principal component.

22. What is Eigenvalue in PCA?

Answer:
It represents the amount of variance explained by a principal component.

23. Explain K-Means Algorithm.

Answer:

Initialize K centroids.
Assign points to the nearest centroid.
Update centroids.
Repeat until convergence.
24. How do you choose K in K-Means?

Answer:
Use the Elbow Method or Silhouette Score.

25. Limitations of K-Means?

Answer:

Sensitive to initialization
Requires predefined K
Sensitive to outliers
Assumes spherical clusters
26. Difference between KNN and K-Means?

Answer:

KNN: Supervised learning.
K-Means: Unsupervised clustering.
27. What is Entropy in Decision Trees?

Answer:
A measure of impurity or randomness in the dataset.

28. What is Gini Index?

Answer:
Another impurity measure used for selecting splits in decision trees.

29. Difference between Entropy and Gini?

Answer:

Entropy uses logarithms and is slightly more computationally expensive.
Gini is simpler and often used by default in CART.
30. Why does Random Forest outperform a single Decision Tree?

Answer:
It reduces variance by averaging predictions from multiple diverse trees.

31. What is Bootstrap Sampling?

Answer:
Sampling with replacement to create different training subsets for ensemble methods.

32. Explain Out-of-Bag (OOB) Error.

Answer:
An internal validation method in Random Forest using samples not included in each bootstrap dataset.

33. What is XGBoost?

Answer:
An optimized gradient boosting algorithm with regularization, parallel processing, and efficient handling of missing values.

34. Why is XGBoost popular?

Answer:

High predictive accuracy
Regularization
Handles missing values
Fast and scalable
35. Difference between Bagging and Boosting?

Answer:

Bagging trains models independently to reduce variance.
Boosting trains models sequentially to reduce bias.
36. What is Data Leakage?

Answer:
When information from outside the training process unintentionally influences the model, leading to overly optimistic performance.

37. What is Class Imbalance?

Answer:
When one class has significantly more samples than another.

38. How do you handle Imbalanced Data?

Answer:

SMOTE
Random over/undersampling
Class weights
Focal loss
Threshold tuning
39. Explain Precision vs Recall.

Answer:

Precision: Important when false positives are costly.
Recall: Important when false negatives are costly.
40. When would you prioritize Recall?

Answer:
Medical diagnosis, fraud detection, and disease screening.

41. When would you prioritize Precision?

Answer:
Spam filtering, recommendation systems, and search ranking where false positives are undesirable.

42. What is ROC-AUC?

Answer:
A metric measuring a classifier's ability to distinguish between classes across different thresholds.

43. What is PR-AUC?

Answer:
The area under the Precision–Recall curve, especially useful for imbalanced datasets.

44. What is Cross Validation?

Answer:
A resampling technique that estimates model performance by training and testing on multiple data splits.

45. Difference between Holdout and Cross Validation?

Answer:

Holdout uses one train-test split.
Cross-validation uses multiple splits, giving a more reliable estimate.
46. Explain Hyperparameter Tuning.

Answer:
Searching for the best hyperparameter values using methods such as Grid Search, Random Search, or Bayesian Optimization.

47. What is Early Stopping?

Answer:
Stopping training when validation performance stops improving to prevent overfitting.

48. Explain the Curse of Dimensionality.

Answer:
As the number of features increases, data becomes sparse, making learning and distance-based methods less effective.

49. What are Feature Importance methods?

Answer:

Random Forest feature importance
Permutation importance
SHAP values
LIME
Mutual information
50. How would you build an end-to-end ML pipeline?

Answer:

Data collection
Data cleaning
Exploratory Data Analysis (EDA)
Feature engineering
Train/validation/test split
Model selection
Hyperparameter tuning
Model evaluation
Deployment
Monitoring and retraining
