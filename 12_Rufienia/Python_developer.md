# Python Interview Questions and Answers

## 1. What are the features of Python?

**Answer:** Python is simple, readable, interpreted, object-oriented,
cross-platform, open source, and has a large standard library.

## 2. Why is Python called an interpreted language?

**Answer:** Python code is executed line by line by the Python
interpreter without requiring compilation to machine code beforehand.

## 3. What are Python's built-in data types?

**Answer:** int, float, complex, bool, str, list, tuple, set, dict,
bytes.

## 4. Difference between List and Tuple?

**Answer:** Lists are mutable; tuples are immutable.

## 5. Difference between == and is?

**Answer:** `==` compares values, while `is` compares object identity.

## 6. What is a dictionary?

**Answer:** A dictionary stores key-value pairs. Keys must be unique and
immutable.

## 7. What is list comprehension?

**Answer:** A concise way to create lists. Example:

``` python
squares = [x*x for x in range(5)]
```

## 8. What is a function?

**Answer:** A reusable block of code that performs a specific task.

## 9. What is recursion?

**Answer:** A function calling itself until a base condition is met.

## 10. What is a lambda function?

**Answer:** An anonymous one-line function. Example:

``` python
square = lambda x: x*x
```

## 11. What is OOP?

**Answer:** A programming paradigm based on classes and objects.

## 12. What is inheritance?

**Answer:** A child class inherits properties and methods from a parent
class.

## 13. What is polymorphism?

**Answer:** The same interface can behave differently for different
objects.

## 14. What is encapsulation?

**Answer:** Wrapping data and methods into a single unit while
restricting direct access.

## 15. What is abstraction?

**Answer:** Hiding implementation details and exposing only essential
functionality.

## 16. What is exception handling?

**Answer:** Handling runtime errors using `try`, `except`, `else`, and
`finally`.

## 17. What are modules?

**Answer:** Python files containing reusable code.

## 18. What is pip?

**Answer:** Python's package manager used to install libraries.

## 19. What is a virtual environment?

**Answer:** An isolated Python environment with its own dependencies.

## 20. Deep copy vs shallow copy?

**Answer:** A shallow copy copies references; a deep copy recursively
copies nested objects.
