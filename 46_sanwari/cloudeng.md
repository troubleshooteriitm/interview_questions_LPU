
# Python & AWS Beginner Interview Questions with Answers

## Python Basics (60)

### 1. What is Python?
**Answer:** Python is a high-level, interpreted, general-purpose programming language known for its simple syntax.

### 2. Why is Python popular?
**Answer:** It is easy to learn, has readable syntax, and is widely used in web development, automation, AI, machine learning, and data science.

### 3. What are the features of Python?
**Answer:** Easy syntax, interpreted, object-oriented, portable, open source, extensive libraries.

### 4. Is Python compiled or interpreted?
**Answer:** Python is interpreted.

### 5. What are variables?
**Answer:** Variables are names used to store values in memory.

### 6. How do you create a variable?
**Answer:** By assigning a value, e.g., `x = 10`.

### 7. What are the basic data types?
**Answer:** int, float, str, bool, list, tuple, set, dict.

### 8. Difference between int and float?
**Answer:** `int` stores whole numbers, while `float` stores decimal numbers.

### 9. What is a string?
**Answer:** A sequence of characters enclosed in single or double quotes.

### 10. What is Boolean?
**Answer:** A data type that has only two values: `True` and `False`.

### 11. What does input() do?
**Answer:** Takes input from the user.

### 12. What does print() do?
**Answer:** Displays output on the screen.

### 13. Why does input() return a string?
**Answer:** Because Python treats keyboard input as text by default.

### 14. What are arithmetic operators?
**Answer:** `+`, `-`, `*`, `/`, `%`, `//`, `**`.

### 15. What are comparison operators?
**Answer:** `==`, `!=`, `>`, `<`, `>=`, `<=`.

### 16. What are logical operators?
**Answer:** `and`, `or`, `not`.

### 17. What is the modulus operator?
**Answer:** `%` returns the remainder after division.

### 18. What is floor division?
**Answer:** `//` returns the quotient without the decimal part.

### 19. Difference between = and ==?
**Answer:** `=` assigns a value; `==` compares two values.

### 20. What is an if statement?
**Answer:** Executes code only if a condition is true.

### 21. What is if-else?
**Answer:** Executes one block if the condition is true, otherwise another block.

### 22. What is elif?
**Answer:** Used to check another condition if the previous one is false.

### 23. Can if exist without else?
**Answer:** Yes.

### 24. What is a nested if?
**Answer:** An if statement inside another if statement.

### 25. What is a loop?
**Answer:** A loop repeatedly executes a block of code.

### 26. Difference between for and while?
**Answer:** `for` is used when the number of iterations is known; `while` runs until a condition becomes false.

### 27. What does range() do?
**Answer:** Generates a sequence of numbers.

### 28. What does break do?
**Answer:** Stops the loop immediately.

### 29. What does continue do?
**Answer:** Skips the current iteration.

### 30. What does pass do?
**Answer:** It is a placeholder that does nothing.

### 31. What is a list?
**Answer:** An ordered, mutable collection.

### 32. Difference between list and tuple?
**Answer:** Lists are mutable; tuples are immutable.

### 33. How do you add an item to a list?
**Answer:** Using `append()`.

### 34. How do you remove an item?
**Answer:** Using `remove()`.

### 35. What is indexing?
**Answer:** Accessing elements using their position.

### 36. What is slicing?
**Answer:** Extracting part of a sequence.

### 37. What is len()?
**Answer:** Returns the length of a sequence.

### 38. What does upper() do?
**Answer:** Converts text to uppercase.

### 39. What does lower() do?
**Answer:** Converts text to lowercase.

### 40. How do you join two strings?
**Answer:** Using the `+` operator.

### 41. What is a function?
**Answer:** A reusable block of code.

### 42. Why do we use functions?
**Answer:** To avoid code repetition and improve readability.

### 43. How do you define a function?
**Answer:** Using the `def` keyword.

### 44. What is a parameter?
**Answer:** A variable in the function definition.

### 45. What is an argument?
**Answer:** The actual value passed to a function.

### 46. What does return do?
**Answer:** Sends a value back to the caller.

### 47. What are comments?
**Answer:** Notes ignored by Python.

### 48. Single-line comment?
**Answer:** Starts with `#`.

### 49. Multi-line comment?
**Answer:** Triple quotes (`'''` or `"""`).

### 50. What are Python keywords?
**Answer:** Reserved words like `if`, `for`, `while`, `def`.

### 51. What is indentation?
**Answer:** Spaces used to define code blocks.

### 52. What is None?
**Answer:** Represents no value or null.

### 53. What is type casting?
**Answer:** Converting one data type to another.

### 54. Difference between list, tuple, and set?
**Answer:** List: ordered & mutable. Tuple: ordered & immutable. Set: unordered & unique values.

### 55. What is a dictionary?
**Answer:** A collection of key-value pairs.

### 56. Difference between append() and extend()?
**Answer:** append() adds one item; extend() adds multiple items.

### 57. Is Python case-sensitive?
**Answer:** Yes.

### 58. What is a syntax error?
**Answer:** An error caused by incorrect Python syntax.

### 59. What is an exception?
**Answer:** A runtime error.

### 60. Why should beginners learn Python?
**Answer:** Because it is simple, versatile, and widely used.

# AWS Basics (20)

1. **What is cloud computing?**  
Answer: Delivering computing services over the internet.

2. **What is AWS?**  
Answer: Amazon Web Services, a cloud computing platform.

3. **What is EC2?**  
Answer: A virtual server service.

4. **What is S3?**  
Answer: Object storage service.

5. **What is IAM?**  
Answer: Identity and Access Management service.

6. **What is an AWS Region?**  
Answer: A geographic area containing AWS data centers.

7. **What is an Availability Zone?**  
Answer: An isolated data center within a Region.

8. **What is an S3 Bucket?**  
Answer: A container for storing files in S3.

9. **What is RDS?**  
Answer: Managed relational database service.

10. **Difference between EC2 and RDS?**  
Answer: EC2 is a virtual machine; RDS is a managed database.

11. **What is VPC?**  
Answer: A private virtual network in AWS.

12. **What is CloudWatch?**  
Answer: Monitoring and logging service.

13. **What is Auto Scaling?**  
Answer: Automatically adjusts EC2 instances based on demand.

14. **What is Elastic Load Balancer?**  
Answer: Distributes traffic across multiple EC2 instances.

15. **What is an IAM User?**  
Answer: An individual account with AWS permissions.

16. **What is an IAM Role?**  
Answer: A temporary identity with permissions.

17. **What is the AWS Free Tier?**  
Answer: Free usage limits for beginners.

18. **What is Pay-as-you-go?**  
Answer: You pay only for the resources you use.

19. **What is a Security Group?**  
Answer: A virtual firewall for EC2 instances.

20. **Name three AWS services.**  
Answer: EC2, S3, IAM.
