# Section 1: Python & Libraries

# Question 1. What's the difference between a List, Tuple, Set, Dictionary, and NumPy Array?

## Answer

Python provides multiple data structures, each designed for different purposes.

- **List** is an ordered and mutable collection that can store different data types. It is the most commonly used collection for general programming.
- **Tuple** is ordered but immutable, making it suitable for storing values that should not change after creation.
- **Set** is an unordered collection of unique elements. It automatically removes duplicates and is useful for membership testing and set operations.
- **Dictionary** stores data as key-value pairs, allowing fast lookups using unique keys.
- **NumPy Array** is designed for numerical computation. It stores elements of the same data type in contiguous memory and supports vectorized operations, making it significantly faster than Python lists for mathematical calculations on large datasets.

For data analysis, Lists and Dictionaries are commonly used for data preparation, while NumPy arrays form the foundation for efficient numerical processing.

# Question 2. Why are NumPy arrays much faster than Python lists?

## Answer

NumPy arrays are optimized for numerical computation. Unlike Python lists, which store references to objects that may have different data types, NumPy arrays store elements of the same data type in contiguous memory. This allows operations to be performed using highly optimized C code instead of Python loops.

NumPy also supports vectorized operations, meaning calculations are applied to an entire array at once instead of processing one element at a time. As datasets grow larger, this results in significant performance improvements.

# Question 3. Explain the difference between `loc` and `iloc` in pandas.

## Answer

Both `loc` and `iloc` are used to select data from a DataFrame, but they work differently.

- **loc** uses row labels and column names.
- **iloc** uses integer positions.

When slicing with `loc`, the ending label is included. With `iloc`, the ending position is excluded, following standard Python slicing behavior.

Choose `loc` when working with labels and `iloc` when working with row positions.

# Question 4. How do you handle missing values in pandas?

## Answer

Handling missing values depends on why the data is missing and how important the missing records are.

Common approaches include:

- Removing rows or columns using `dropna()`
- Replacing missing values using `fillna()`
- Filling numeric values with the mean or median
- Filling categorical values with the mode
- Using forward fill or backward fill for sequential data
- Applying model-based imputation for more complex datasets

Before choosing a method, it is important to understand whether the missing values occurred randomly or follow a specific pattern.

# Question 5. What is the difference between `merge()`, `join()`, and `concat()` in pandas?

## Answer

These functions combine DataFrames but serve different purposes.

- **merge()** combines DataFrames using one or more common columns, similar to SQL joins.
- **join()** is mainly used to combine DataFrames based on their indexes.
- **concat()** simply stacks DataFrames either vertically or horizontally without performing relational matching.

Use `merge()` for database-style joins, `join()` for index-based operations, and `concat()` when appending datasets together.

# Question 6. Explain the difference between `apply()`, `map()`, and `applymap()`.

## Answer

These functions apply operations to pandas objects at different levels.

- **map()** works only on a single Series and performs element-wise transformations.
- **apply()** works on both Series and DataFrames and can process rows or columns.
- **applymap()** performs element-wise operations across an entire DataFrame.

Whenever possible, vectorized pandas or NumPy operations should be preferred because they are significantly faster than these methods.

# Question 7. Why should you avoid using `for` loops on large DataFrames?

## Answer

Python loops process one row at a time, introducing significant interpreter overhead. Pandas and NumPy are designed to perform operations on entire columns using optimized C implementations.

Using vectorized operations reduces execution time dramatically and results in cleaner, more readable code. For very large datasets, avoiding explicit loops can improve performance by several times.

# Question 8. What is a GroupBy operation in pandas?

## Answer

`groupby()` is used to split data into groups based on one or more columns, perform calculations on each group, and combine the results into a single output.

This process is commonly known as the **Split → Apply → Combine** pattern.

GroupBy is frequently used to calculate totals, averages, counts, minimums, maximums, and other summary statistics for categories such as products, regions, or customers.

# Question 9. How do you detect and handle outliers using Python?

## Answer

Outliers can be detected using statistical methods such as the Interquartile Range (IQR), Z-score, or by visualizing the data with box plots and histograms.

Once identified, the analyst should determine whether the outlier is a genuine business event or a data error. Incorrect values may be corrected or removed, while legitimate extreme values should generally be retained unless the analysis requires otherwise.

# Question 10. What is the difference between `is` and `==` in Python?

## Answer

The `==` operator compares whether two objects have the same value.

The `is` operator compares whether two variables reference the same object in memory.

For checking whether a variable is `None`, the recommended approach is to use `is None` instead of `== None` because it checks object identity rather than value equality.

# Question 11. What are list comprehensions, and why are they preferred over traditional loops?

## Answer

A list comprehension is a concise way to create a new list by combining iteration and optional filtering into a single expression. Compared to a traditional `for` loop, list comprehensions are shorter, easier to read for simple transformations, and generally faster because they reduce the overhead of repeatedly calling methods like `append()`.

However, if the logic becomes complex or spans multiple conditions, a regular `for` loop is usually more readable and easier to maintain.

# Question 12. What are Python decorators, and where are they useful in data projects?

## Answer

A decorator is a function that extends or modifies the behavior of another function without changing its original code. Decorators are applied using the `@decorator_name` syntax.

In data engineering and analytics projects, decorators are commonly used for logging, measuring execution time, retrying failed API requests, caching expensive computations, and validating function inputs. They help reduce duplicate code and improve maintainability.

# Question 13. What is the difference between `*args` and `**kwargs`?

## Answer

Both `*args` and `**kwargs` allow a function to accept a variable number of arguments.

- `*args` collects additional positional arguments into a tuple.
- `**kwargs` collects additional keyword arguments into a dictionary.

They are useful when writing reusable functions where the number or names of arguments are not known in advance.

# Question 14. What is Python's Global Interpreter Lock (GIL), and how does it affect performance?

## Answer

The Global Interpreter Lock (GIL) allows only one thread to execute Python bytecode at a time within a single process.

Because of this, multithreading does not significantly improve performance for CPU-intensive tasks. For computational workloads, multiprocessing is generally preferred because it uses separate processes that can run in parallel. For I/O-bound tasks such as reading files, calling APIs, or querying databases, multithreading remains effective because threads spend much of their time waiting for external resources.

# Question 15. What is the difference between a shallow copy and a deep copy?

## Answer

A shallow copy creates a new object but still shares references to nested objects with the original. Changes made to nested objects may therefore affect both copies.

A deep copy creates a completely independent duplicate of the original object, including all nested objects. Changes made to one copy do not affect the other.

Understanding this difference is important when working with complex Python objects or pandas DataFrames to avoid unintended modifications.

# Question 16. How would you process a CSV file that is too large to fit into memory?

## Answer

Large CSV files should be processed in smaller chunks instead of loading the entire dataset into memory.

Common approaches include:

- Reading the file in chunks using pandas.
- Selecting only the required columns.
- Specifying data types to reduce memory usage.
- Processing each chunk independently and combining the results.
- Using distributed libraries such as Dask or Polars for extremely large datasets.

For production environments, it is often better to perform heavy processing inside a database instead of loading the full dataset into Python.

# Question 17. What is the difference between `None`, `numpy.nan`, and `pd.NA`?

## Answer

Although all three represent missing values, they are designed for different purposes.

- `None` is Python's built-in null object and can be used with any data type.
- `numpy.nan` represents missing numeric data and is primarily used in NumPy arrays and floating-point columns.
- `pd.NA` is pandas' newer missing-value representation that works consistently across multiple data types, including integers, booleans, and strings.

For modern pandas applications, `pd.NA` is generally the preferred choice because it provides more consistent handling of missing values.

# Question 18. What is vectorization, and why is it important in NumPy and pandas?

## Answer

Vectorization means performing an operation on an entire array or column at once instead of processing one element at a time.

NumPy and pandas use optimized low-level implementations to execute vectorized operations much faster than Python loops. This leads to better performance, cleaner code, and improved scalability when working with large datasets.

Whenever possible, vectorized operations should be preferred over explicit loops.

# Question 20. What does `SettingWithCopyWarning` mean in pandas?

## Answer

`SettingWithCopyWarning` indicates that pandas cannot determine whether you are modifying the original DataFrame or a temporary view of it.

This warning often appears when chained indexing is used. To avoid unexpected behavior, create an explicit copy when needed and use `.loc[]` for assignments instead of chained indexing.

Following these practices ensures that updates are applied correctly and improves code reliability.

# Question 21. What are lambda functions, and when should you use them?

## Answer

A lambda function is a small anonymous function defined using the `lambda` keyword. They are commonly used when a simple function is required for a short period, such as with sorting, filtering, mapping, or applying transformations in pandas.

Lambda functions improve code readability for simple operations, but regular functions are preferred when the logic becomes complex or needs to be reused.

# Question 22. What are generators, and how are they different from lists?

## Answer

A list stores all of its elements in memory at once, while a generator produces values one at a time only when they are needed.

Because generators generate values lazily, they consume much less memory and are well suited for processing large datasets or streams of data. Lists are preferable when data needs to be accessed repeatedly or randomly.

Time complexity measures how an algorithm's execution time grows as the size of the input increases.

Although Data Analysts primarily use high-level libraries, understanding time complexity helps in selecting efficient algorithms and writing scalable code. Inefficient operations that work well on small datasets can become major performance bottlenecks when processing millions of records.

# Question 25. What are some best practices for writing efficient pandas code?

## Answer

Writing efficient pandas code improves both performance and maintainability.

Some recommended practices include:

- Prefer vectorized operations over loops.
- Use appropriate data types to reduce memory usage.
- Avoid chained indexing.

# Section 2: SQL

# Question 26. What is the difference between `WHERE` and `HAVING`?

## Answer

Both `WHERE` and `HAVING` are used to filter data, but they operate at different stages of query execution.

- **WHERE** filters individual rows before grouping and aggregation.
- **HAVING** filters groups after the `GROUP BY` clause has been applied and aggregate functions have been calculated.

Use `WHERE` whenever possible because it reduces the amount of data processed, making queries more efficient. Use `HAVING` only when filtering based on aggregate values such as `COUNT()`, `SUM()`, or `AVG()`.

# Question 27. Explain the different types of SQL JOINs.

## Answer

JOINs combine data from multiple tables based on a related column.

- **INNER JOIN** returns only matching rows from both tables.
- **LEFT JOIN** returns all rows from the left table and matching rows from the right table.
- **RIGHT JOIN** returns all rows from the right table and matching rows from the left table.
- **FULL OUTER JOIN** returns all rows from both tables, filling unmatched values with `NULL`.

Choosing the correct join depends on the business requirement and the data you want to retrieve.

# Question 28. What is the difference between `UNION` and `UNION ALL`?

## Answer

Both operators combine the results of multiple queries.

- **UNION** removes duplicate rows before returning the final result.
- **UNION ALL** returns every row, including duplicates.

Because `UNION` performs duplicate removal, it requires additional processing and is generally slower. If duplicate rows are acceptable or impossible, `UNION ALL` is the better choice.

# Question 29. What is the purpose of the `GROUP BY` clause?

## Answer

The `GROUP BY` clause groups rows that share the same values into a single group. It is commonly used with aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()` to calculate summary statistics for each group.

It is frequently used in reporting to summarize sales, customers, departments, products, or other business categories.

# Question 30. What are aggregate functions in SQL?

## Answer

Aggregate functions perform calculations across multiple rows and return a single result.

The most commonly used aggregate functions are:

- `COUNT()` – Counts records.
- `SUM()` – Calculates the total.
- `AVG()` – Calculates the average.
- `MIN()` – Returns the smallest value.
- `MAX()` – Returns the largest value.

Aggregate functions are typically used together with the `GROUP BY` clause to generate summary reports.

# Question 31. What is a subquery?

## Answer

A subquery is a query written inside another SQL query. The result of the inner query is used by the outer query to retrieve or filter data.

Subqueries can appear in `SELECT`, `FROM`, or `WHERE` clauses and are useful when one query depends on the result of another. Although they are powerful, complex subqueries can sometimes be rewritten using joins or Common Table Expressions (CTEs) for better readability and performance.

# Question 32. What is a Common Table Expression (CTE)?

## Answer

A Common Table Expression (CTE) is a temporary named result set created using the `WITH` clause. It exists only during the execution of the query.

CTEs improve readability by breaking complex queries into smaller logical steps. They can also be referenced multiple times within the same query and support recursive queries, making them useful for hierarchical data.

# Question 33. What are window functions, and how are they different from `GROUP BY`?

## Answer

Window functions perform calculations across a group of rows while preserving every individual row in the result.

Unlike `GROUP BY`, which combines rows into a single summary row, window functions allow each row to retain its original values while also receiving additional calculated information such as rankings, running totals, or moving averages.

They are widely used in reporting and analytical queries.

# Question 34. What is the difference between `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`?

## Answer

These window functions assign rankings to rows, but they handle ties differently.

- **ROW_NUMBER()** assigns a unique sequential number to every row.
- **RANK()** gives the same rank to tied values but skips the next rank.
- **DENSE_RANK()** also gives the same rank to tied values but does not skip subsequent rankings.

Choosing the correct function depends on how tied values should be handled.

# Question 35. What is the difference between `EXISTS` and `IN`?

## Answer

Both are used to test whether matching data exists.

- **IN** compares a value against a list or the results of a subquery.
- **EXISTS** checks whether the subquery returns at least one row.

For large datasets, `EXISTS` is often more efficient because it stops searching as soon as a matching row is found, whereas `IN` may evaluate the complete result set.

# Question 36. What is the `CASE` statement in SQL?

## Answer

The `CASE` statement adds conditional logic to SQL queries. It works similarly to an `if-else` statement in programming languages.

It is commonly used to create calculated columns, categorize data, replace values, or generate conditional reports without modifying the underlying data.

Conditional logic using `CASE` improves the flexibility and readability of SQL queries.

# Question 37. What is a SQL View?

## Answer

A View is a virtual table created from the result of a SQL query. It does not usually store data itself but displays data retrieved from one or more underlying tables.

Views simplify complex queries, improve security by restricting access to specific columns, and provide a consistent interface for reporting.

Changes made to the underlying tables are automatically reflected in the view.

# Question 38. What is an Index, and why is it important?

## Answer

An index is a database object that improves the speed of data retrieval by allowing the database engine to locate rows more efficiently.

Without an index, the database may need to scan the entire table to find matching records. While indexes improve read performance, they require additional storage and can slightly slow insert, update, and delete operations because the index must also be maintained.

# Question 39. What is database normalization?

## Answer

Normalization is the process of organizing data to reduce redundancy and improve data integrity.

It divides data into related tables connected through keys, reducing duplicate information and making updates more consistent. While normalization improves data quality, highly normalized databases may require additional joins, which can impact query performance.

For analytical systems, some level of denormalization is often preferred to improve reporting speed.

# Question 40. What is the difference between a Primary Key and a Foreign Key?

## Answer

A **Primary Key** uniquely identifies each row in a table. It cannot contain duplicate or NULL values.

A **Foreign Key** establishes a relationship between two tables by referencing the Primary Key of another table. Foreign keys help maintain referential integrity and ensure that related records remain consistent across the database.

# Question 41. What is the difference between a Clustered Index and a Non-Clustered Index?

## Answer

An index improves the speed of data retrieval by helping the database locate records efficiently.

- A **Clustered Index** determines the physical order in which data is stored in a table. Since data can only be stored in one order, a table can have only one clustered index.
- A **Non-Clustered Index** stores the indexed values separately from the actual table data and points back to the corresponding rows. A table can have multiple non-clustered indexes.

Clustered indexes are ideal for range queries and frequently sorted data, while non-clustered indexes are commonly used to speed up searches on frequently filtered columns.

# Question 42. What is the difference between `DELETE`, `TRUNCATE`, and `DROP`?

## Answer

Although all three remove data, they serve different purposes.

- **DELETE** removes selected rows from a table and can include a `WHERE` clause. The table structure remains unchanged.
- **TRUNCATE** removes all rows from a table much faster than `DELETE` because it deallocates the data pages. It cannot remove selected rows.
- **DROP** removes the entire table, including its structure, indexes, and data.

Use `DELETE` when removing specific records, `TRUNCATE` when clearing a table, and `DROP` only when the table is no longer needed.

# Question 43. What is a SQL Transaction?

## Answer

A transaction is a sequence of one or more SQL operations that are treated as a single unit of work.

A transaction ensures that either all operations are completed successfully or none of them are applied. This prevents databases from entering inconsistent states if an error occurs during execution.

Transactions are commonly controlled using commands such as:

- `BEGIN TRANSACTION`
- `COMMIT`
- `ROLLBACK`

Transactions are especially important in banking, e-commerce, and financial applications where data consistency is critical.

# Question 44. What are the ACID properties?

## Answer

ACID is a set of properties that ensure database transactions remain reliable.

- **Atomicity** ensures that all operations in a transaction succeed together or fail together.
- **Consistency** guarantees that the database remains in a valid state before and after a transaction.
- **Isolation** prevents transactions from interfering with each other while running simultaneously.
- **Durability** ensures that once a transaction is committed, the changes remain permanent even if the system crashes.

These properties help maintain the accuracy and reliability of database systems.

# Question 45. What is a correlated subquery?

## Answer

A correlated subquery is a subquery that depends on values from the outer query. Unlike a regular subquery, it is executed once for each row processed by the outer query.

Although correlated subqueries can solve complex problems, they may become slow on large datasets because the inner query executes repeatedly. In many cases, they can be rewritten using joins or window functions to improve performance.

# Question 46. How do you optimize a slow SQL query?

## Answer

Improving SQL performance begins with identifying the bottleneck rather than making random changes.

Some common optimization techniques include:

- Creating indexes on frequently filtered or joined columns.
- Avoiding `SELECT *` and retrieving only the required columns.
- Filtering rows as early as possible.
- Replacing correlated subqueries with joins or window functions when appropriate.
- Reviewing the execution plan to identify expensive operations.
- Ensuring statistics and indexes are up to date.

Effective optimization reduces query execution time and improves database performance.

# Question 47. What is the PIVOT operation in SQL?

## Answer

A PIVOT operation converts row values into columns, making the data easier to summarize and report.

For example, monthly sales stored as separate rows can be transformed into a report where each month becomes a separate column. This format is commonly used in business reports and dashboards.

When a database does not support the `PIVOT` operator, the same result can often be achieved using `CASE` expressions with aggregate functions.

# Question 48. What is the difference between Normalization and Denormalization?

## Answer

Normalization reduces data redundancy by splitting information into multiple related tables. It improves data consistency and minimizes duplicate data.

Denormalization combines related data into fewer tables to reduce joins and improve query performance. Although it increases redundancy, it is commonly used in reporting systems and data warehouses where fast read performance is more important than storage efficiency.

Operational databases generally favor normalization, while analytical systems often use denormalization.

# Question 49. What is the difference between a Primary Key, Composite Key, and Unique Key?

## Answer

These keys help maintain data integrity but serve different purposes.

- A **Primary Key** uniquely identifies each row and cannot contain NULL values.
- A **Composite Key** consists of two or more columns that together uniquely identify a record.
- A **Unique Key** prevents duplicate values but usually allows a NULL value depending on the database system.

Choosing the correct key depends on the structure of the data and business requirements.

# Question 50. What is the difference between a View and a Materialized View?

## Answer

Both are used to simplify complex queries, but they store data differently.

A **View** is a virtual table that executes its underlying query whenever it is accessed. It always displays the latest data but may be slower for complex queries.

A **Materialized View** stores the query results physically. Since the data is already computed, queries execute much faster. However, the stored data must be refreshed periodically to reflect changes in the underlying tables.

Materialized views are commonly used in reporting and data warehousing environments where query performance is more important than real-time updates.

# Section 3: Statistics & Data Analysis

# Question 51. What is the difference between descriptive and inferential statistics?

## Answer

Statistics can be broadly divided into two categories.

- **Descriptive Statistics** summarize and describe the characteristics of a dataset using measures such as mean, median, mode, standard deviation, and charts.
- **Inferential Statistics** use sample data to make predictions or draw conclusions about an entire population through techniques such as hypothesis testing and confidence intervals.

Descriptive statistics explain what the data shows, while inferential statistics help make decisions beyond the observed data.

# Question 52. What are Mean, Median, and Mode?

## Answer

These are measures of central tendency that describe the center of a dataset.

- **Mean** is the arithmetic average of all values.
- **Median** is the middle value after arranging the data in order.
- **Mode** is the value that occurs most frequently.

The mean is affected by extreme values, while the median is more robust when the dataset contains outliers. The mode is especially useful for categorical data.

# Question 53. What is Standard Deviation?

## Answer

Standard deviation measures how spread out the data points are around the mean.

- A **low standard deviation** indicates that most values are close to the mean.
- A **high standard deviation** indicates that the values are widely dispersed.

It is commonly used to measure variability, consistency, and risk in data analysis.

# Question 54. What is Variance?

## Answer

Variance measures the average squared difference between each data point and the mean.

A larger variance indicates greater variability within the dataset, while a smaller variance indicates that the values are more consistent.

Standard deviation is simply the square root of variance and is often preferred because it is expressed in the same units as the original data.

# Question 55. What is the difference between Population and Sample?

## Answer

A **population** includes every member of the group being studied.

A **sample** is a subset of the population selected for analysis.

Since collecting data from an entire population is often expensive or impractical, analysts usually work with samples and use statistical methods to make conclusions about the population.

# Question 56. What is the difference between Population Mean and Sample Mean?

## Answer

The **population mean** represents the average of every value in the entire population and is usually denoted by the symbol **μ (mu)**.

The **sample mean** represents the average of the selected sample and is denoted by **x̄ (x-bar)**.

The sample mean is commonly used as an estimate of the population mean.

# Question 57. What is Probability?

## Answer

Probability measures the likelihood that an event will occur.

Its value ranges from:

- **0** → The event is impossible.
- **1** → The event is certain.

Probability forms the foundation of statistical analysis, predictive modeling, and machine learning.

# Question 58. What are Normal Distribution and Bell Curve?

## Answer

A normal distribution is a symmetric probability distribution where most observations are concentrated around the mean.

Important characteristics include:

- Mean, median, and mode are equal.
- The distribution is symmetric.
- Most observations lie near the center, with fewer observations toward the extremes.

Many statistical techniques assume that data follows a normal distribution.

# Question 59. What is Skewness?

## Answer

Skewness measures the asymmetry of a data distribution.

- **Positive skew** means the distribution has a longer tail on the right.
- **Negative skew** means the distribution has a longer tail on the left.
- **Zero skew** indicates a perfectly symmetric distribution.

Understanding skewness helps analysts choose appropriate statistical methods.

# Question 60. What are Outliers, and why are they important?

## Answer

Outliers are observations that differ significantly from the rest of the data.

Outliers may occur because of:

- Data entry errors.
- Measurement errors.
- Rare but valid events.

Before removing outliers, analysts should determine whether they represent genuine business events or incorrect data. Removing valid outliers can lead to misleading conclusions.

# Question 61. What is Correlation?

## Answer

Correlation measures the strength and direction of the relationship between two variables.

The correlation coefficient ranges from **-1** to **+1**.

- **+1** indicates a perfect positive relationship.
- **0** indicates no linear relationship.
- **-1** indicates a perfect negative relationship.

It is important to remember that **correlation does not imply causation**.

# Question 62. What is Covariance?

## Answer

Covariance measures whether two variables move together.

- A **positive covariance** indicates that both variables tend to increase or decrease together.
- A **negative covariance** indicates that one variable tends to increase while the other decreases.

Unlike correlation, covariance does not have a fixed range, making it harder to interpret directly.

# Question 63. What is Hypothesis Testing?

## Answer

Hypothesis testing is a statistical method used to determine whether there is enough evidence to support a claim about a population.

It begins with two hypotheses:

- **Null Hypothesis (H₀)** – Assumes there is no significant effect or difference.
- **Alternative Hypothesis (H₁)** – Assumes that a significant effect or difference exists.

Based on the sample data, analysts decide whether there is sufficient evidence to reject the null hypothesis.

# Question 64. What is a p-value?

## Answer

A p-value measures how likely the observed results would occur if the null hypothesis were true.

- A **small p-value** indicates strong evidence against the null hypothesis.
- A **large p-value** suggests that the observed results could reasonably occur by chance.

A significance level of **0.05** is commonly used, although the threshold may vary depending on the application.

# Question 65. What is a Confidence Interval?

## Answer

A confidence interval provides a range of values that is likely to contain the true population parameter.

Instead of reporting a single estimate, confidence intervals express the uncertainty associated with sample-based estimates.

A **95% confidence interval** is commonly used in statistical analysis because it provides a practical balance between precision and confidence.

# Question 67. Explain the LEGB rule.

## Answer

LEGB defines the order in which Python searches for a variable.

- **L – Local:** Variables inside the current function.
- **E – Enclosing:** Variables in the enclosing (outer) function.
- **G – Global:** Variables defined at the module level.
- **B – Built-in:** Python's built-in names such as `len()`, `print()`, and `range()`.

If the name is not found in any of these scopes, Python raises a `NameError`.

# Question 73. What is duck typing?

## Answer

Duck typing is a feature of Python where the type of an object is less important than the methods and attributes it provides.

In simple terms:

> "If it looks like a duck and behaves like a duck, Python treats it as a duck."

As long as an object supports the required methods, it can be used regardless of its actual class.

# Question 74. What is Method Resolution Order (MRO)?

## Answer

Method Resolution Order (MRO) defines the order in which Python searches for methods and attributes when multiple inheritance is used.

Python follows the **C3 Linearization Algorithm** to determine this order.

The MRO of a class can be viewed using:

- `ClassName.mro()`
- `ClassName.__mro__`

Understanding MRO helps avoid ambiguity in multiple inheritance.

# Question 75. What are Python virtual environments?

## Answer

A virtual environment is an isolated Python environment created for a specific project.

It allows each project to maintain its own Python interpreter and package versions without affecting other projects.

Benefits include:

- Prevents dependency conflicts.
- Improves project reproducibility.
- Makes collaboration easier.
- Follows Python development best practices.
