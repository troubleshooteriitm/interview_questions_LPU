# 5. What is REST API?

**Answer:**

REST API is an architectural style that allows communication between client and server using HTTP methods like GET, POST, PUT, and DELETE.

---

# 6. What is Fetch API?

**Answer:**

Fetch API is a JavaScript interface used to make HTTP requests to servers asynchronously. It returns a Promise.

Example:

```javascript
fetch(url)
  .then(response => response.json())
  .then(data => console.log(data));
```

# 7. What is asynchronous programming?

**Answer:**

Asynchronous programming allows JavaScript to execute other tasks while waiting for long-running operations like API calls.

---

# 8. What is a Promise?

**Answer:**

A Promise represents the eventual completion or failure of an asynchronous operation.

States:
- Pending
- Fulfilled
- Rejected
