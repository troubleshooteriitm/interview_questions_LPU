## Question 31. What is Machine Learning?

**Answer:** Machine Learning is a branch of AI that enables computers to
learn from data and make predictions without explicit programming.

**Answer:** Supervised Learning, Unsupervised Learning, and

**Answer:** AI is the broad field, ML is a subset of AI that learns from
data, and Deep Learning is a subset of ML using deep neural networks.

**Answer:** Supervised Learning trains a model using labeled data to

## Question 37. What is an Artificial Neural Network (ANN)?

hidden, and output layers.

## Question 38. What is Overfitting and Underfitting?

**Answer:** Overfitting memorizes training data and performs poorly on
new data. Underfitting fails to learn enough from the data.

## Question 39. What is the difference between Training Data and Testing Data?

## Question 43. What is the difference between a List and a Tuple?

**Answer:** Lists are mutable and use square brackets `[]`, while tuples
are immutable and use parentheses `()`. Lists are used when data needs
to change, whereas tuples are used for fixed data.

## Question 44. What is the difference between a List and a Set?

**Answer:** A list maintains order and allows duplicate values. A set
stores only unique values and is mainly used when duplicates should be
removed.

## Question 45. What is a Dictionary in Python?

**Answer:** A dictionary stores data as key-value pairs. Each key is
unique and allows fast retrieval of its associated value.

## Question 46. What is Object-Oriented Programming (OOP)?

**Answer:** OOP is a programming paradigm based on classes and objects.
It improves code reusability, modularity, and maintainability.

## Question 47. Explain the four pillars of OOP.

**Answer:** The four pillars are Encapsulation, Inheritance,
Polymorphism, and Abstraction.

## Question 48. What is Exception Handling?

**Answer:** Exception handling prevents a program from crashing due to
runtime errors using `try`, `except`, `else`, and `finally` blocks.

## Question 49. What is the difference between `==` and `is`?

**Answer:** `==` compares the values of two objects, while `is` checks
whether two variables refer to the same object in memory.

## Question 50. What is a Lambda Function?

**Answer:** A lambda function is a small anonymous function created
using the `lambda` keyword, commonly used with functions like `map()`,
`filter()`, and `sorted()`.

## Question 51. What is a Data Structure?

**Answer:** A data structure is a way of organizing and storing data so
it can be accessed and modified efficiently.

## Question 52. Why are Data Structures important?

**Answer:** Data structures improve the efficiency of algorithms by
optimizing searching, insertion, deletion, and data management.

## Question 53. What is an Array?

**Answer:** An array is a linear data structure that stores elements of
the same type in contiguous memory locations and provides fast indexed
access.

## Question 54. What are the advantages and disadvantages of Arrays?

**Answer:** Arrays provide fast access and simple traversal but have a
fixed size and expensive insertion and deletion operations.

## Question 55. What is a Linked List?

**Answer:** A linked list is a linear data structure made of nodes,
where each node contains data and a reference to the next node.

## Question 56. Difference between Array and Linked List?

**Answer:** Arrays use contiguous memory and provide O(1) indexing,
while linked lists use dynamic memory allocation and offer efficient
insertion and deletion.

## Question 57. What is a Stack?

**Answer:** A stack is a linear data structure that follows the LIFO
(Last In, First Out) principle. Common operations are Push, Pop, and
Peek.

## Question 58. What is a Queue?

**Answer:** A queue is a linear data structure that follows the FIFO
(First In, First Out) principle. Common operations are Enqueue and
Dequeue.

## Question 59. Difference between Stack and Queue?

**Answer:** A stack follows LIFO, while a queue follows FIFO. Stacks use
one end for operations, whereas queues use both ends.

## Question 60. What is Time Complexity?

**Answer:** Time complexity measures how an algorithm's execution time
grows as the input size increases. It is commonly expressed using Big O
notation, such as O(1), O(log n), O(n), and O(n²).
## Question 61. What is Big O Notation?

**Answer:** Big O Notation describes how the time or space complexity of
an algorithm grows as the input size increases. Common complexities
include O(1), O(log n), O(n), O(n log n), O(n²), and O(2ⁿ).

## Question 62. What is Recursion?

**Answer:** Recursion is a technique in which a function calls itself to
solve smaller instances of the same problem. Every recursive function
has a base case and a recursive case.

## Question 63. What is Binary Search?

**Answer:** Binary Search is an efficient searching algorithm used on
sorted arrays. It repeatedly divides the search space into halves until
the target element is found. Its time complexity is O(log n).

## Question 64. Why is Binary Search O(log n)?

**Answer:** Binary Search halves the search space after every
comparison, so the number of operations grows logarithmically with the
input size.

## Question 65. What is a HashMap?

**Answer:** A HashMap stores data as key-value pairs using a hash
function. It provides average O(1) time complexity for insertion,
deletion, and searching.

## Question 66. What is a Tree?

**Answer:** A tree is a hierarchical, non-linear data structure
consisting of nodes connected by edges. It is widely used in file
systems, databases, and hierarchical data representation.

## Question 67. What is a Binary Search Tree (BST)?

**Answer:** A Binary Search Tree is a binary tree where all values in
the left subtree are smaller than the root and all values in the right
subtree are greater. Average search, insertion, and deletion take O(log
n).

## Question 68. What is a Heap?

**Answer:** A Heap is a specialized binary tree that satisfies the heap
property. In a Max Heap, the parent is greater than its children; in a
Min Heap, the parent is smaller than its children.

## Question 69. What is the difference between BFS and DFS?

**Answer:** BFS (Breadth-First Search) explores nodes level by level
using a queue, while DFS (Depth-First Search) explores one branch
completely before backtracking, using a stack or recursion.

## Question 70. What is Dynamic Programming (DP)?

**Answer:** Dynamic Programming is an optimization technique that solves
problems with overlapping subproblems by storing previously computed
results using memoization or tabulation.

## Question 71. What is DBMS?

**Answer:** A Database Management System (DBMS) is software used to
create, store, retrieve, update, and manage databases efficiently.

## Question 72. What is the difference between DBMS and RDBMS?

**Answer:** DBMS stores data without requiring relationships, while
RDBMS stores data in related tables using primary and foreign keys and
supports relational operations.

## Question 73. What is a Primary Key?

**Answer:** A Primary Key uniquely identifies each record in a table. It
cannot contain NULL values and must be unique.

## Question 74. What is a Foreign Key?

**Answer:** A Foreign Key is a column that references the Primary Key of
another table to establish relationships and maintain referential
integrity.

## Question 75. What is Normalization?

**Answer:** Normalization is the process of organizing database tables
to reduce redundancy and improve data integrity through forms such as
1NF, 2NF, and 3NF.

## Question 76. What is the difference between DELETE, TRUNCATE, and DROP?

**Answer:** DELETE removes selected rows, TRUNCATE removes all rows
while keeping the table, and DROP deletes the entire table along with
its structure.

## Question 77. What are SQL Joins?

**Answer:** SQL Joins combine rows from multiple tables. Common joins
are INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN.

## Question 78. What are ACID Properties?

**Answer:** ACID stands for Atomicity, Consistency, Isolation, and
Durability. These properties ensure reliable and consistent database
transactions.

## Question 79. What is an Index in SQL?

**Answer:** An Index improves the speed of data retrieval by allowing
the database to locate rows quickly, though it requires additional
storage and maintenance.

## Question 80. What is a Transaction?

**Answer:** A Transaction is a sequence of database operations treated
as a single unit of work. It either completes entirely or is rolled back
if any operation fails.
